# TechBridge

A web-based chat application supporting both direct messaging and group chats.

## Key Features

### Communication
- One-on-one messaging
- Group chat functionality
- User-friendly chat interface
### Conversation Summarization
Generates concise summaries of chat conversations using the Gemini API, allowing users to quickly review key discussion points.
### Technical Term Explanation
Provides contextual explanations for technical terms when users hover over them, helping participants better understand specialized vocabulary.
### Automatic Translation
Automatically translates messages according to each user's preferred language settings, enabling smoother communication between users from different linguistic backgrounds.

## Tech Stack

- Python
- Django
- HTML/CSS
- JavaScript
- Gemini API
